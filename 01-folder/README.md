# React + Vite App

A simple React project built with Vite for fast development and modern tooling.

## Features

- React with Vite
- Fast Refresh
- ESLint support
- Easy project structure

## Getting Started

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

## Project Structure

```text
src/
├── assets/
├── App.jsx
├── main.jsx
└── index.css
```

## Available Plugins

This template supports:

- `@vitejs/plugin-react`
- `@vitejs/plugin-react-swc`

## Notes

- React Compiler is not enabled by default.
- If needed, you can extend ESLint for stricter production checks.
